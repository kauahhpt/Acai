Política de Privacidade

Última atualização: 9 de outubro de 2026

Esta política explica como o Pé de Açaí trata os dados pessoais de quem usa o nosso site para consultar o cardápio, criar uma conta e fazer pedidos.

1. Quem é o responsável

O responsável pelo tratamento dos dados é o Pé de Açaí. Para qualquer questão sobre privacidade, contacta-nos em ESCREVE-AQUI-O-TEU-EMAIL.

2. Que dados recolhemos

  • Dados da conta: nome, email e palavra-passe. A palavra-passe é guardada de forma cifrada pelo serviço de autenticação e nós não a conseguimos ver.
  • Entrar com Google: se escolheres esta opção, recebemos apenas o teu nome e o teu endereço de email da conta Google. Não temos acesso a mais nada da tua conta Google.
  • Dados de entrega: a morada, se a indicares para receberes pedidos.
  • Pedidos: o conteúdo do que pedes.

3. Para que usamos os dados

  • Criar e gerir a tua conta e manter a tua sessão iniciada.
  • Receber, preparar e entregar os teus pedidos.
  • Contactar-te sobre um pedido, se for necessário.

Não usamos os teus dados para publicidade e não os vendemos a ninguém.

4. Onde ficam guardados

Os dados são guardados no Supabase, que fornece a base de dados e a autenticação, e o site está alojado no Netlify. Estes prestadores tratam os dados apenas para nos prestar o serviço. Se enviares um pedido pelo WhatsApp, aplicam-se também as regras do WhatsApp.

5. Armazenamento no teu navegador

Guardamos no teu navegador a informação necessária para manteres a sessão iniciada. Não usamos cookies de publicidade nem de rastreamento.

6. Durante quanto tempo guardamos os dados

Guardamos os dados enquanto a tua conta existir. Podes pedir a eliminação da conta e dos dados associados a qualquer momento.

7. Os teus direitos

Nos termos do Regulamento Geral sobre a Proteção de Dados (RGPD), tens direito a aceder aos teus dados, a corrigi-los, a pedir o seu apagamento, a opor-te ao tratamento e a receber uma cópia deles. Para exercer estes direitos, envia-nos um email para o endereço indicado acima. Podes também apresentar reclamação à Comissão Nacional de Proteção de Dados (CNPD).

8. Alterações a esta política

Se esta política mudar, a data de atualização no topo da página também muda.
